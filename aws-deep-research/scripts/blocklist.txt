# Domain blocklist for aws-deep-research
# One domain per line. Blank lines and lines starting with # are ignored.
# Matching is done by suffix: "example.com" also blocks "sub.example.com".
#
# Entries are written DEFANGED (winbuzzer[.]com) so this file contains no
# live domain that a content/security scanner would read as a real URL.
# The loader (common.py) un-defangs "[.]" back to "." at read time, so
# matching still works on the real host.
#
# These domains are filtered out of Brave/Tavily results BEFORE URLs are
# returned for fetchv2 batch fetching, and also skipped when listed in
# urls_*.txt files.
#
# Reasons a domain ends up here:
#   SEC   - Amazon Security / corporate policy blocks the domain
#   SPAM  - low-signal aggregator, scraped-content mill, or SEO farm
#   PAY   - hard paywall that adds noise without content
#   DEAD  - persistently broken / timing out
